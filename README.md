# 看见看不见 —— 平面镜成像 × 镜面对称（八年级跨学科 PBL 互动课件）

单文件 HTML 课件，零依赖，浏览器直接打开即可投屏上课。

- **学科**：数学（八年级上册 轴对称 · 镜面对称建模）× 物理（八年级上册 平面镜成像）
- **课型**：跨学科数学建模 PBL 新授课，1 课时（建议 45 分钟）
- **环节**：入项魔盒挑战 → 探究成像规律与虚像 → 建模（点化/建系/归纳/轴对称/一般化/拆穿）→ 三关反馈 → 结项任务发布

## 在线地址

**https://a-chen1109.github.io/see-the-unseen/**

部署方式：GitHub Pages「Deploy from a branch」，源为 `main` 分支根目录。每次 push 到 `main` 后约 30 秒生效。

## 操作方式

| 操作 | 说明 |
|---|---|
| ← → | 翻页（最常用） |
| PageUp / PageDown / 空格 | 翻页 |
| Home / End | 首页 / 末页 |
| 屏幕两侧箭头、底栏按钮 | 鼠标翻页 |
| 左右滑动 | 平板触屏 |
| 顶栏环节按钮 | 跳转到该环节第一页 |
| 顶栏 A+ / A- | 调整字号 |
| 顶栏 ☀ | 深色 / 浅色切换（教室亮建议切浅色） |
| 顶栏 · 点 开/关 | 背景动态点开关 |
